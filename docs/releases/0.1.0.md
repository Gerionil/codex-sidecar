# Codex Sidecar 0.1.0 — First public preview

A free, MIT-licensed macOS companion for Codex by Gerionil.

## Included

- Menu-bar panel and resizable companion window with shared chat selection.
- Searchable chat list with stored titles and recent activity ordering.
- Passive account limits and observed completed-response token accounting.
- Cache metrics, model/window metadata, paginated requests and compact task activity.
- System, Light and Dark appearance, native Dock and menu-bar icons.
- Offline mode with automatic recovery when quota access is resumed.
- Local processing with no model inference, telemetry or metrics database.

## Download

`Codex-Sidecar-0.1.0-macos-arm64.zip` contains the ready-to-run Apple Silicon app,
MIT license and installation instructions. `SHA256SUMS.txt` provides its SHA-256
checksum. Source archives are also available separately through GitHub.

**No Apple Developer ID signature or notarization is included.** macOS may block
first launch; consult the [installation guide](https://github.com/Gerionil/codex-sidecar/blob/v0.1.0/docs/INSTALL.md).
Apple signing and notarization are deferred by the owner.

## Validation and limitations

- The fresh release-preparation suite passed 200 tests with zero failures.
- Release build and app packaging passed on Apple Silicon macOS 27.0.1.
- Native acceptance covers the current Mac; Intel is not included and macOS
  14–26 runtime support is unverified despite the declared macOS 14 minimum.
- Codex CLI `0.160.1` is the checked profile. Internal log formats and app-server
  capabilities may change in other versions.
- Exact current context usage and foreground-chat detection are unavailable.
- VoiceOver acceptance is excluded; simultaneous natural-response updates on
  both surfaces were not observed. Paired synthetic native updates were verified.
- Observed totals reflect inspected records, not guaranteed lifetime usage or
  billing. Quotas are account-wide and independent of the selected chat.

Please report bugs through [GitHub Issues](https://github.com/Gerionil/codex-sidecar/issues)
without private logs, prompts, credentials or personal screenshots.
