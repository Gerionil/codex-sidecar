# Donation QR assets

Owner-provided public receiving addresses, approved for the project donation
block on 2026-10-08. The root README lists the exact asset/network for each image.

Each PNG encodes the plain receiving address, without an amount, payment URI,
contract address or network metadata. The donor must select the correct asset
and network in their wallet. Images include a four-module white quiet zone.

Generated locally using macOS Core Image. All four saved PNGs were independently
decoded using Apple Vision and matched the owner-provided addresses exactly.
TRON Base58Check and Bitcoin/Litecoin Bech32 checksum checks passed. These checks
do not establish wallet ownership, token support or successful receipt; no funds
were transferred. No private keys or recovery phrases are included.
