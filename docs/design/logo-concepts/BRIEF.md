# Codex Sidecar logo exploration

## Brief and assumptions

Name: Codex Sidecar. A passive, local macOS companion for account limits and
observed selected-chat usage. Tone: calm, precise, compact, approachable.
The approved interface uses a restrained Codex-inspired light/dark palette.
The symbol must be distinct from the OpenAI knot and remain legible in a
monochrome macOS menu-bar template image. Dock artwork may use a rounded tile,
with the same underlying mark. No wordmark is needed inside either icon.

This is a concept checkpoint, not a production icon set. No application assets
or code are changed. The remote skill was read from a temporary checkout and
was not installed globally. Source:
https://github.com/kaankiziltug/logo-design-skill/blob/main/skills/logo-design/SKILL.md

## Strategy and longlist

Word map: sidecar / beside / companion / independent / quiet / glance / C / S.
Category research: the bundled developer-tools library has frequent rings,
brackets, abstract geometry and blue palettes. Avoid robot heads, AI sparkles,
chat bubbles, terminal glyphs and the OpenAI knot. Library files were inspected
for construction, not copied: Pagekit, Patreon, Framer; orbit references were
searched separately. This is a limited reference comparison, not clearance.

Scores below are informal 1–5 design judgments: clarity, distinction, simplicity,
relevance, small-size strength.

| Idea | Scores | Decision |
| --- | --- | --- |
| Companion: a detached capsule inside the opening of a C | 5/4/5/5/5 | A |
| Ribbon: an asymmetric continuous S with offset ends | 5/3/5/4/5 | B |
| Orbit: an open circular C with a detached rounded satellite | 5/2/5/4/4 | C |
| Paired windows: one large and one small loop | 4/3/3/5/3 | Too much framing at small sizes |
| Parallel rails: staggered rounded bars | 3/2/5/4/5 | Too generic |
| Fold: two returning right-angle corners | 3/3/4/3/4 | Too close to code brackets |
| Notched disc with negative S | 3/3/3/4/3 | Lower immediate legibility |
| Twin crescents sharing an axis | 3/2/4/4/3 | Too much orbit symbolism |

## Construction and refinement

All symbols use a 256-unit square, one solid fill, geometric paths and no live
text, filters, embedded raster artwork or strokes. A uses a rounded C with a
32-unit wall and a detached horizontal capsule. B uses two returning circular
curves and asymmetrical ends. C uses concentric circular arcs and a detached
rounded square.

First audit/render pass: inspected the concept sheet at large and 64/32/16 px.
Second pass: A capsule reduced to 28 units high to widen its separation; B moved
8 units right and 16 up for optical balance; C moved 6 units left. Meaningful
versions retained. V2 audit reports no warnings/errors; B/C retain informational
vertical-centering notes consistent with their optical placement.

Recommendation: A. It has the clearest relation to the app's name, with a quiet
side element that survives reduction. B has strong legibility but a broad S
category; C feels friendly but its orbit construction is more familiar.
