# Public demo

`sidecar-demo.gif` is the README tour; `sidecar-demo.mp4` is the H.264 version
for sharing. Both are 25 seconds at 960 × 760, with five scenes held for five
seconds each. `poster.png` is the opening scene.

The scenes introduce the menu panel, searchable chat selector, observed usage,
light appearance and project download. They reuse the actual native interface
renders described in [screenshots](../screenshots/README.md), with English
presentation captions. This is an interface slideshow, not a screen recording
of live interactions. It does not simulate pointer clicks or a live quota read.

All account/chat values are synthetic. No private records, credentials or
special model requests were used. The Apple Silicon/unsigned-preview limitation
is visible throughout. The application and its release archive are unchanged.
